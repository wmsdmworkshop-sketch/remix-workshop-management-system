# Service Advisor Workspace Accessibility

This document outlines the accessibility compliance standards met by the **Service Advisor Workspace**.

## 1. Compliance Standards

### Semantic HTML
- Content sections are grouped using standard HTML5 tags (`<main>`, `<nav>`, `<section>`).
- Forms, inputs, and interactive components feature unique ID attributes for automated testing.

### ARIA Attributes
- Buttons and state controls include detailed ARIA labels (`aria-label`) and state variables (`aria-expanded`, `aria-checked`).

### Contrast & Focus
- Interactive elements display clear focus borders for keyboard navigators.
- High-contrast typography colors meet WCAG AA visibility standards on dark layouts.
