# DWIP v1.0 Administrator Manual

This manual provides operational instructions for system administrators managing **DWIP v1.0**.

## 1. User Management
- **Role assignments**: Assign roles (e.g. `service_advisor`, `qc_inspector`, `technician`) in the User Directory view.
- **Permission settings**: Adjust toggle checkmarks in the RBAC permissions matrix.

## 2. Server Monitoring
- Check memory footprint logs and API latencies in the **System Hardening** tab.
- Monitor active database pools to verify connection health.
