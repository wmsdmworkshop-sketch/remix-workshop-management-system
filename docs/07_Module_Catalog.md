# DWIP Module Catalog
**Package & Module Registries**

## 1. Platforms Modules
* **analytics**: Handles fact records indexing, KPI calculations, metrics bootstrapping, and aggregation logic.
* **customer-experience**: Compiles Customer 360 interactions timeline, fleet profiles, lead registers, and appointment configurations.
* **enterprise-ai**: Features predictive reasoning, model versions metadata registry, decision logs audits, and explainability.
* **executive**: presentation layer compiling dashboard widget collections for dealership roles.

## 2. Core Modules
* **event-bus**: In-memory event subscriber and outbox queue flushing coordinator.
* **identity**: Employee profiles authentication and permission middleware.
* **event-engine**: Telemetry service TAT trackers, timeline loggers, and replay engines.
