# DWIP v1.0 User Training Manual

This manual provides onboarding guidelines for staff members transition to **DWIP v1.0**.

## 1. Quick Start Guidelines
1. Log in to the DWIP terminal using assigned username credentials.
2. Select your workspace tab from the sidebar menu layout (Advisor, Supervisor, Technician, QC).
3. Follow the highlighted action prompts in your console dashboard.
4. Enforce digital signatures and photos capture checks prior to finalizing repair stages.
