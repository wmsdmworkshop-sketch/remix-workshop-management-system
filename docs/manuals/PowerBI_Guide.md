# DWIP v1.0 Power BI Integration Guide

This guide details steps to link the **DWIP v1.0** dashboard data into **Power BI Desktop**.

## 1. Integration Steps
1. Navigate to the **Power BI Analytics** tab in the DWIP workspace.
2. Select **Download Dataset** to export the structured JSON dataset (`PowerBI_Global_Dataset.json`).
3. Open Power BI Desktop, click **Get Data**, and select **JSON**.
4. Import the downloaded JSON file to build visualizations.
