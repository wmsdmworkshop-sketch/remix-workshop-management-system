# DWIP v1.0 User Manual

This manual provides instructions for workshop staff using the **DWIP v1.0** console.

## 1. Service Advisor
- Use the **Advisor Workspace** to track incoming vehicles, register complaints, complete digital inspections, and build labor/parts estimates.

## 2. Floor Supervisor
- Use the **Supervisor Workspace** to assign technicians and bays to job cards. Check recommendations on the AI Copilot.

## 3. Technician
- Use the **Technician Workspace** to check assigned jobs, track labor times, and capture repair photos.

## 4. QC Inspector
- Use the **QC Workspace** to run mechanical checklist checks, road tests, and log final PASS/FAIL validation decisions.
