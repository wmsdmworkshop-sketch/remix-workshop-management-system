## 1. Dealer Principal & CEO Guide
* **Dashboard Monitoring**: Log into the executive dashboard portal to inspect forecasted workshop revenue, active branches comparisons, and system alerts.
* **Review Cycle**: Validate KPI status flags monthly.

## 2. Service Advisor User Guide
* **Vehicle Check-in**: Open the reception form, enter customer mobile, vehicle registration, and active complaints details.
* **Estimations**: Map parts rates, select contract coverage (AMC/Warranty), and request customer approval.

## 3. Technician & Floor User Guide
* **Bay Clock-in**: Click "Start Repair" to record task commencement.
* **Rework Logs**: Register any rework complaints with appropriate failure code details.
