# AiVaahan Mobile Device Compatibility Matrix

**Target Application**: AiVaahan DWIP (`com.aivaahan.dwip`)

---

## Hardware & Operating System Specifications

| Hardware Attribute | Minimum Requirement | Recommended Specification |
| :--- | :--- | :--- |
| **Android Operating System** | Android 7.0 (API Level 24) | Android 12.0 – 14.0 (API Level 31 – 34) |
| **System RAM** | 3 GB RAM | 4 GB to 8 GB RAM |
| **Processor (CPU)** | Octa-Core 1.8 GHz | Octa-Core 2.2 GHz+ (Snapdragon / MediaTek) |
| **Internal Storage** | 500 MB Available | 2 GB+ Available |
| **Display Resolution** | 720 x 1280 (HD) | 1080 x 2400 (FHD+) |
| **Camera** | 8 MP with Auto-Focus | 12 MP+ with Flash & HDR |
| **Location (GPS)** | GPS / A-GPS Support | Multi-GNSS (GPS, GLONASS, NavIC) |
| **Connectivity** | 4G LTE / Wi-Fi 802.11 b/g/n | 5G / Wi-Fi 5 GHz |

---

## Verified Device Tiers

- **Tier 1 (Supported Enterprise Devices)**: Samsung Galaxy A-Series (A14/A34/A54), Redmi Note 12/13, Realme 11/12, Vivo Y-Series.
- **Tier 2 (Legacy Support)**: Android 7.0 – 9.0 devices with >= 3 GB RAM.
- **Battery Optimization**: Configured to bypass aggressive battery-saver killing for `com.aivaahan.dwip` background sync.
