## Platform Overview

DWIP Enterprise is designed around two foundational pillars:
1. **Workshop Operating System (WOS)**: Event-driven workshop execution core providing real-time bay TAT tracking, job card state machines, dual-timeline auditing, and AI copilot optimization.
2. **Integration Layer (Sprint IL-001)**: Modular plugin-based gateway enabling external systems (TMSA, DMS, FleetEdge, custom connectors) to communicate via normalized DWIP models without touching core business logic.
