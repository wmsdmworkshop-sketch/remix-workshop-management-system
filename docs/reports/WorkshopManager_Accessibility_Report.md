# Workshop Manager Accessibility Report

This document reports on the accessibility audit conducted on the **Workshop Manager UI Components**.

## 1. Compliance Level
- **Target Standards**: WCAG 2.1 Level AA Compliance.
- **Result**: **Fully Compliant**.

## 2. Implemented Accessibility Features
- **Semantic Tags**: Components leverage standard HTML5 elements (`select`, `button`, `article`, `header`, `h1` through `h4`).
- **Keyboard Navigation**: Interactive elements support focus-states, allowing tab index navigation.
- **ARIA Annotations**: Added `aria-label`, `role="alert"`, `aria-live="assertive"`, and screen reader labels.
- **Contrast Ratios**: Strictly uses dark-mode design system colors matching high contrast ratios.
- **Localisation/Language Tagging**: Main wrapper explicitly declares language settings (`lang="en"`).
