# Service Advisor Component Map

This document outlines the components structure of the **Service Advisor Workspace**.

## 1. Components Layout
- **ServiceAdvisorWorkspace**: Parent container managing view tab switching (Overview, Reception, Digital Inspection, Estimate Builder).
- **Inspection Checklist deck**: Grid togglers checking exterior, interior, tyres, battery, leaks, lights, and brakes safety statuses.
- **Complaint Builder**: Text fields, priority dropdown selectors, and AI auto-symptom suggestions.
- **Estimate Workspace**: Price calculators with WhatsApp, Email, and SMS approval transmitters.
- **AI Assistant Copilot**: Gemma-powered telemetry checking and parts recommendation panel.
