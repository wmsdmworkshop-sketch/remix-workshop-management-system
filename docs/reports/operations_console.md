# Operations Cockpit User Guide

Guides administrators on using the unified Operations Command Center.

## Dashboard Sections
- **System Health**: CPU, RAM, Disk, MySQL connections, and active background worker status. Includes live heat maps and queue monitors.
- **Live Events**: Realtime event bus telemetry.
- **Timeline Replay**: Vehicle journey timeline simulator.
- **AI Inspector**: Confidence scores and prompt logs audit.
- **Database**: Statistics and index recommendation lists.
- **Logs Explorer**: Filterable process logs query engine.
- **Audit Center**: Secure workflow history logs.
- **Production Support Mode**: Overrides for Maintenance Mode, Read Only, Safe Mode, and queue restarts.
