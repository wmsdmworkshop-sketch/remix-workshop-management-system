# Floor Supervisor Component Map

This document outlines the components structure of the **Floor Supervisor Workspace**.

## 1. Components Layout
- **FloorSupervisorWorkspace**: Container displaying navigation tabs (Dashboard, Twin, Roster, Allocation).
- **Digital Twin Grid**: Interactive cards displaying bay name, occupancy flags, active vehicle VRNs, and assigned technicians.
- **Technician control**: Tabulated list checking technician names, certification levels, and FTR rates.
- **Allocation panel**: Select dropdowns triggering manual re-allocations of techs and bays to job cards.
- **AI Copilot**: Panel displaying recommendation details, sequences, and confidence scores.
