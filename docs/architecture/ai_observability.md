# AI Reasoning & Audit System

Describes the AI Observability parameters tracked for recommendations.

## Tracked Parameters
Every AI-generated recommendation captures:
- Copilot Engine model version.
- Prompt Version.
- Evaluated business rules.
- Accessed Knowledge Graph nodes.
- Confidence Score.
- Human Approval status.
- Final outcome.
- User rating.

## Explainability Console
The explainability tab exposes the underlying reasoning behind the suggestion:
- **Why**: Rationale.
- **Evidence**: Specific data points utilized.
- **Historical Cases**: Similar database matches.
- **Alternatives**: Secondary options.
