# Sedam Road & Basavakalyan User Training Checklist

**Target Personnel**: Workshop Personnel across `BR-SEDAM` and `BR-BASAVAKALYAN`

---

## Role-Based Training Verification Checklist

### 1. Gate Security Personnel
- [x] Mobile PWA & App login.
- [x] Vehicle Gate In intake registration (Registration #, Chassis #, Driver Mobile).
- [x] Gate Out verification and pass generation.

### 2. Service Advisors
- [x] VOS Session creation and inspection.
- [x] Job Card state transition (`GATE_IN` → `WORK_IN_PROGRESS`).
- [x] Repair estimation and customer approval logging.

### 3. Technicians & QRT Drivers
- [x] QRT Breakdown acceptance and mobile navigation.
- [x] GPS location logging at dispatch, arrival, and repair complete.
- [x] Vehicle inspection photo capture and gateway media upload.

### 4. Workshop Managers & GM Service
- [x] Multi-branch executive dashboard navigation.
- [x] Technician productivity and advisor performance scorecards.
- [x] Incident escalation procedures (Level 1 → Level 2 → Level 3).
