# ADR-008: Enterprise Event Bus
**Status**: Approved
**Context**: Deep coupling between route controllers and dependent workflows (e.g. notifications, SLA resets) makes updates difficult.
**Decision**: Implement the decoupled `EventBus` supporting wildcard subscriptions, retry policies, and metadata propagation.
**Alternatives**: Direct synchronous function calling inside controller loops.
**Consequences**: Decoupled systems, high trace capability via Correlation IDs, and async execution resiliency.
