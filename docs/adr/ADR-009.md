# ADR-009: Timeline Engine
**Status**: Approved
**Context**: Reconstructing vehicle repair histories and calculating Turnaround Time (TAT) metrics is error-prone.
**Decision**: Implement an append-only, immutable Event Store that logs every workflow transition, user action, and diagnostic state. Metrics are derived by replaying these events chronologically.
**Alternatives**: Overwriting status columns directly in tables without history ledgers.
**Consequences**: Complete trace history and auditable process bottlenecks.
