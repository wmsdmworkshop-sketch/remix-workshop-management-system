# ADR-006: Knowledge Engine
**Status**: Approved
**Context**: Workshop diagnostic workflows require access to OEM service circulars and standard diagnostic SOPs.
**Decision**: Implement the Knowledge Intelligence Platform (KIP) to ingest, extract, and index metadata, verifying document statuses before exposing them.
**Alternatives**: Storing unparsed PDF circulars in a flat folder and performing basic file lookups.
**Consequences**: Secure and formatted metadata that can be directly passed to Gemini model contexts.
