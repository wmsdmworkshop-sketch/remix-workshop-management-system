# ADR-004: Golden Repair
**Status**: Approved
**Context**: Recommending standard repairs requires separating low-quality, temporary fixes from high-quality, permanent solutions.
**Decision**: Standardize and define the "Golden Repair" as a benchmark repair path. Comebacks (reworks within a specific threshold) are flagged automatically, and only repairs with zero comebacks are promoted to Golden Repair status.
**Alternatives**: Relying purely on technician feedback to define standard repairs.
**Consequences**: Data-backed, objective repair paths that can feed automated parts reservation engines.
