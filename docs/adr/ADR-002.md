# ADR-002: Metadata First Evidence
**Status**: Approved
**Context**: Workshop evidence assets (such as road tests, checklists, and inspections) contain heavy data payloads and media.
**Decision**: Store only structured metadata models in the primary database, mapping evidence records to external binary resources. 
**Alternatives**: Storing binary blobs or large JSON structures inline. Rejected due to database pool performance degradation and storage cost inflation.
**Consequences**: Fast query responses, minimal data payload, and clean separation of binary files.
