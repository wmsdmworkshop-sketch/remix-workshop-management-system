# ADR-005: Rules Engine
**Status**: Approved
**Context**: Workshop operational business rules (e.g. reorder thresholds, overtime limits, and SLA levels) tend to evolve frequently.
**Decision**: Externalize all business rules into a dedicated evaluation service (DRE rules engine) and retrieve parameters from the database, eliminating hardcoded logic in routes.
**Alternatives**: Hardcoding conditions directly inside API controllers.
**Consequences**: Managers can change rules instantly in the database without code redeployments.
