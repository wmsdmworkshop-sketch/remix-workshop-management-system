# ADR-003: Repair DNA
**Status**: Approved
**Context**: Complex vehicle diagnostics require mapping specific complaints to symptoms, investigation checks, and execution calibrations.
**Decision**: We implement Repair DNA modeling to serialize the exact diagnostic pathway, technical calibrations, and outcomes for every repair task.
**Alternatives**: Simple generic text description fields. Rejected as text does not permit structured rule evaluation or AI similarity search.
**Consequences**: Standardized calibration logging and high diagnostic quality checks.
