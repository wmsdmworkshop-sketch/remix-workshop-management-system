# ADR-010: Temporary Upload Policy
**Status**: Approved
**Context**: Ingesting user circulars, PDFs, and diagnostic images poses security and storage retention risks.
**Decision**: Implement a strict immediate destruction policy. Temporary files uploaded for metadata extraction (SOP parsing or OCR) must be processed in-memory or deleted from temporary storage immediately after parsing.
**Alternatives**: Retaining all historical source files indefinitely on disk.
**Consequences**: Reduced attack surface, SAIF compliance, and low storage overhead.
