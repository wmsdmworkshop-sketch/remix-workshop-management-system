# Workshop Manager Multi-Workshop View

This document specifies the multi-workshop view hierarchy designed to scale from a single dealership up to enterprise-level regional analytics.

## 1. Multi-Workshop Target Sites
The dashboard includes built-in selection filters for the following Tata WMS locations:
- **Kalaburagi** (Main Central Hub)
- **Gulbarga** (Regional Workshop)
- **Basavakalyan** (EV Specialist Cluster)
- **Shahapur** (Sub-district Support Center)

## 2. Access Levels & Scopes
- **Single Workshop View**:
  - Displays the live operational layout of one specific branch.
  - Used by local Floor Supervisors and Workshop Managers.
- **Regional View**:
  - Displays aggregated charts (revenue, bay utilization, total open job cards) for all workshops in the region.
- **Enterprise View**:
  - Read-only KPI overview dashboard for the Dealer Principal and executive managers.
  - Compares FTR (First Time Right) scores, revenue totals, and SLA compliance percentages side-by-side.
