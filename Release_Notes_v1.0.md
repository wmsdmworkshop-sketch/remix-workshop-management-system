# Devanand Automobiles LLP — DWIP v1.0 Release Notes

We are proud to release version 1.0 of the **Devanand Workshop Intelligence Platform (DWIP)**.

## 1. Feature Highlights
- **Unified Operational Cockpits**: Dedicated, role-specialized workspaces for Service Advisors, Floor Supervisors, Technicians, and QC Inspectors.
- **Automated AI Copilots**: Gemma-powered models suggesting technicians, forecasting stockouts, and identifying hidden repair defects.
- **Power BI Exports**: Exposes structured JSON datasets for enterprise dashboards analytics.
- **Hardened Security**: Multi-tier prepared statement wrappers and strict Role-Based Access Controls (RBAC).
