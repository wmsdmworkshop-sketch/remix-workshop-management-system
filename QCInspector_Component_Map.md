# Quality Control Component Map

This document outlines the components structure of the **Quality Control Inspector Workspace**.

## 1. Components Layout
- **QCInspectorWorkspace**: Parent dashboard layout wrapper managing view tabs (Dashboard, Checklist, Road Test, Decision Center).
- **Validation Checklist deck**: Grid buttons toggling approvals for mechanical, electrical, and brakes items.
- **Road Test Panel**: Speed, distance trackers, and alignment check flags.
- **Decision Center**: Select dropdown log PASS/FAIL indicators with rework reasons and tech feedbacks.
- **AI Copilot specs**: Suggests hidden defect checks, warranty risks, and checklist completeness warnings.
